# notchGPT 2.1.0

- Compact, continuous native notch panels with matching 76 pt extensions and configurable dial colors.
- Independent allowance statistics and daily charts with 30-minute bars across both four-hour work windows.
- Ten recent chat links, remote computer names and distinct running, waiting-for-input, notified and stopped states.
- Persistent pins with drag-and-drop ordering, cancellation and scrolling.
- Slow orange/blue attention pulses, combined alerts and background checks while the panel is closed.
- Optional hover opening (off by default) and Reduce Motion support.

## Download and verification

The universal ZIP supports Apple Silicon and Intel Macs running macOS 13 or later. Verify it using the accompanying SHA-256 checksum file.

The app is ad-hoc signed, not Developer ID signed or notarized. Build from source if that better fits your macOS security policy. The app reads existing Codex metadata and sign-in information for its documented read-only features; see SECURITY.md for details.
